# hololive-timeline
A timeline detailing hololive debuts, graduations, transfers and live events.
You can view this timeline in your browser using the following link: [https://www.timelines.studio/viewer/gh/collin33/hololive-timeline/main/hololive-timeline.timeline](https://www.timelines.studio/viewer/gh/collin33/hololive-timeline/main/hololive-timeline.timeline).

This repo makes use of Timelines Studio, an open source project for making and viewing timelines. You can visit their work over on their [github repository](https://github.com/sreegjl/timelines).
